# 01 · 需求与范围

## 1. 产品定位

个人自用、本地离线的密码管理器。数据存本机数据库，落盘加密；解锁后界面可明文查看与复制（不做逐字段遮罩的强交互，但复制/展示行为要有记录与安全收尾）。

## 3. MVP（第一个可用版本）范围

对应阶段 1–5 的闭环：

- 首次启动设置主密码 → 解锁进入主界面。
- 左侧分类（全部 / 自定义分类，增删改）；右侧条目列表。
- 条目字段：标题、账号、密码、邮箱、手机号、网址、备注（Markdown）。
- 新增/编辑条目：弹窗窗口内完成；备注区支持 Markdown 编辑 + 预览。
- 账号/邮箱/手机号可从个人预设值下拉选择；每个字段带复制按钮。
- 内置强密码生成器：长度、大小写、数字、符号、排除易混字符可选；生成后可填入密码字段并随条目保存。
- 敏感字段在 Rust 侧加密后写入 SQLite；界面解锁后明文展示。
- 导出加密备份文件 / 从备份恢复；数据库文件可手动拷贝迁移；WebDAV 仅预留配置与同步接口，不实现真实联网。
- 中英文可切换，词条走 i18n。

## 4. 非目标（MVP 明确不做，避免范围蔓延）

- 浏览器扩展 / 自动填充。
- TOTP 动态验证码。
- 多设备实时双向同步、冲突合并（仅预留 WebDAV 上传密文的接口）。
- KDBX / Bitwarden / CSV 导入导出（列入后续路线）。
- 生物识别 / Windows Hello 快速解锁。
- 团队协作、账号体系、遥测上报。
- 移动端 App。

## 5. 后续路线（参考，详见 `08-roadmap.md`）

搜索与排序、收藏、回收站、弱密码/重复密码安全检查、空闲自动锁定、深浅色主题、CSV/KDBX 导入导出、TOTP、真实 WebDAV 同步、生物识别解锁、浏览器扩展、安装包打包与 CI。

## 6. 关键边界与风险

- **主密码不可找回**：加密根密钥由主密码派生；主密码丢失则数据无法恢复，需在首次启动与文档中明确提示。
- **本机高权限内存 Dump 不在防护范围内**：自用场景接受此边界，但会话密钥用完即清、锁定即销毁。
- **WebDAV 只传密文**：即使后续实现同步，远端也只能拿到加密后的库文件，服务端不可读。
