# 05 · MVP 功能规格

本文定义第一个可用版本的交互与字段行为。布局与术语以中英文词条为准（见 `07-i18n.md`），不在组件里硬编码文案。

## 1. 总体布局（图标导航栏 + 左右结构）

```
┌────┬───────────────┬────────────────────────────────────────────────┐
│ 图 │ 侧栏（分类）   │  条目列表（当前分类）                           │
│ 标 │               │                                                │
│ 导 │  全部 (n)     │  ┌──────────────────────────────────────┐     │
│ 航 │  工作 (n)     │  │ 标题                 [收藏] [更多]     │     │
│ 栏 │  生活 (n)     │  │ 账号  ******  [复制]                   │     │
│    │  回收站 (n)   │  │ 密码  ******  [复制] [生成]            │     │
│ 首 │  ＋ 新增分类  │  │ 邮箱  ******  [复制]                   │     │
│ 预 │               │  │ 备注：Markdown 摘要 …… [打开编辑]       │     │
│ ── │               │  └──────────────────────────────────────┘     │
│ 语 │               │                                                │
│ 设 │               │                                                │
│ 锁 │               │                                                │
└────┴───────────────┴────────────────────────────────────────────────┘
```

- 最左侧图标导航栏（`components/layout/NavRail.vue`，宽 14）：上方为首页（条目）、预设值；下方为语言切换（图标，点击在中/英间切换）、设置、锁定。图标一律用 `lucide-vue-next`；每项带 `title` 与 `aria-label`，当前页高亮并置 `aria-current="page"`。
- 左侧：分类树（MVP 单层），含"全部""未分类""回收站"；每项显示条目数；分类支持新增/重命名/删除。
- 右侧：当前分类下的条目卡片/行列表；顶部搜索框按标题、账号、邮箱、手机号、备注过滤（备注为密文，前端解密后在内存中匹配）；支持按"最近更新 / 名称 / 收藏优先"排序。
- 回收站：删除条目先进回收站，可恢复或彻底删除，支持清空；回收站内不提供复制与编辑。
- 页面切换：`/main`（条目）、`/presets`（预设值）、`/settings`（设置）共用一个外壳 `components/layout/AppShell.vue`，导航栏常驻；解锁页 `/unlock` 独立不带导航栏。原顶部栏已移除。

## 2. 条目字段

| 字段 | 录入方式 | 展示 | 复制 |
| --- | --- | --- | --- |
| 标题 title | 手输，必填 | 列表主标题 | — |
| 账号 username | 手输 + 账号预设下拉 | 显示明文（解锁态） | 每行复制按钮 |
| 密码 password | 手输 / 生成器填入 | 默认可明文显示，提供显示/隐藏切换 | 复制按钮 + 生成入口 |
| 邮箱 email | 手输 + 邮箱预设下拉 | 明文 | 复制按钮 |
| 手机号 phone | 手输 + 手机预设下拉 | 明文 | 复制按钮 |
| 网址 url | 手输 | 可点击打开 + 复制 | 复制按钮 |
| 备注 notes | Markdown 编辑器（弹窗） | 列表显示摘要/预览片段 | 打开编辑弹窗 |

### 2.1 预设值（R6）

- 在独立的"预设值"页面（`/presets`，导航栏第二项）维护"我的预设"：按字段类型（账号 / 邮箱 / 手机号 / 常用密码）分 Tab 分组，每组用 naive-ui `NDataTable` 展示（虚拟滚动，适合大量数据），每条有显示名 + 值；设置页不再包含预设管理。
- 表单对应字段旁提供下拉，选择后填入值；密码字段也从"常用密码"下拉取值。预设值落盘一律加密（见 `04` `presets` 表），仅在解锁态内存中明文显示，密码类不做遮挡、不额外隐藏。
- 预设值可新增/编辑/删除；"常用密码"只是手动登记的候选值，强密码仍首选生成器。

### 2.2 字段复制（R7）

- 每个可复制字段右侧独立复制按钮，点击后写入剪贴板并给出 Toast 反馈。
- 复制后到设定时间自动清空剪贴板（默认 30 秒，可关闭）；只在剪贴板内容仍是刚复制的那段文字时才清空，读取受限时跳过。
- 复制动作不触发联网；剪贴板历史由操作系统管理，本应用不写额外记录。

## 3. Markdown 备注（R4 / R5）

- **编辑**：条目通过"打开备注/编辑条目"进入独立弹窗（Dialog；后续可替换为独立 `WebviewWindow`）。备注区为 Markdown 编辑，带基础工具栏（标题、加粗、斜体、链接、列表、代码块、引用）。
- **预览**：弹窗内 Tabs 切换"编辑 / 预览"，预览在渲染层关闭原始 HTML、只放行 `http/https` 链接。MVP 用自研白名单渲染器（`src/lib/markdown.ts`，先转义再生成固定标签），未引入第三方 Markdown 库；后续如需完整语法可替换为 markdown-it 且保持同等安全约束。
- **列表展示**：右侧条目卡片只显示备注纯文本摘要（去除 Markdown 标记，截断行数），完整内容在弹窗查看。
- 备注全文加密落库（`notes_enc`）。

## 4. 强密码生成器（R8）

- 入口：条目表单密码字段旁"生成"按钮，或独立生成器面板。
- 选项：
  - 长度滑块/输入（建议 12–64，默认 16）。
  - 复选：大写 `A-Z`、小写 `a-z`、数字 `0-9`、符号 `!@#$…`。
  - 开关：排除易混字符（`0 O l 1 I` 等）。
  - 至少保证选中字符集里出现各类字符（若勾选了多类，结果每类至少一个）。
- 行为：本地 CSPRNG 生成；提供"重新生成"；可"填入密码字段"；随条目一并保存（保存时走加密落库）。
- 生成器本身不持久化密码，除非用户保存为条目。

## 5. 新增 / 编辑 / 删除条目

- 新增：右侧"新增条目"按钮 → 弹窗表单 → 保存入当前分类（可在表单内改分类）。
- 编辑：卡片"更多 → 编辑"或点击卡片 → 弹窗回填 → 保存更新 `updated_at`。
- 删除：二次确认；MVP 物理删除（`deleted_at` 字段已预留回收站）。
- 所有写操作经 Rust 命令，事务内完成；失败回滚并 Toast 报错。

## 6. 解锁与主密码（衔接 R9）

- 首次启动：设置主密码（最短 4 位；强度提示为长度/字符类的参考信息，不强制），确认两次一致。
- 启动：未解锁只显示解锁页；校验通过进主界面。
- 顶部"锁定"：清空会话密钥回到解锁页；锁定后前端列表不再持有明文。
- 主密码修改、恢复码等列入后续路线，MVP 只做设置/解锁/锁定。

## 7. 验收要点（MVP 可演示闭环）

1. 能创建分类、在分类下新增条目，字段含账号/密码/邮箱/手机/网址/Markdown 备注。
2. 预设下拉可选已保存的账号/邮箱/手机号；每个字段可一键复制。
3. 生成器可调选项生成强密码，填入并保存到条目。
4. 备注可在弹窗编辑 Markdown、切换预览；列表显示摘要。
5. 关闭重开程序需主密码解锁；直接查数据库文件看不到账号/密码/邮箱/手机/备注明文。
6. 界面可在中/英文间切换，切换后顶部与主要文案跟随。
7. 可导出加密备份文件，并能从该文件恢复；数据库文件可手动拷贝迁移（见 `06`）。
