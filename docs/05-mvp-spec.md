# 05 · MVP 功能规格

本文定义第一个可用版本的交互与字段行为。布局与术语以中英文词条为准（见 `07-i18n.md`），不在组件里硬编码文案。

## 1. 总体布局（左右结构）

```
┌──────────────────────────────────────────────────────────────────┐
│  [Logo] Mend        [语言切换 zh|en]          [搜索] [锁定] [设置] │
├───────────────┬──────────────────────────────────────────────────┤
│ 侧栏（分类）   │  条目列表（右侧）                                  │
│               │                                                  │
│  全部 (n)     │  ┌────────────────────────────────────────┐    │
│  工作 (n)     │  │ 标题                [收藏] [更多]        │    │
│  生活 (n)     │  │ 账号  ******  [复制]                      │    │
│  购物 (n)     │  │ 密码  ******  [复制] [生成]               │    │
│  金融 (n)     │  │ 邮箱  ******  [复制]                      │    │
│  ＋ 新增分类  │  │ 手机  ******  [复制]                      │    │
│               │  │ 备注：Markdown 摘要 …… [打开编辑]          │    │
│               │  └────────────────────────────────────────┘    │
└───────────────┴──────────────────────────────────────────────────┘
```

- 左侧：分类树（MVP 单层），含"全部"与"未分类"；每项显示条目数；支持新增/重命名/删除。
- 右侧：当前分类下的条目卡片/行列表；顶部搜索框按标题、账号、邮箱、手机号过滤（备注全文检索列入后续）。
- 顶部栏：左侧 Logo + 软件名 **Mend**；软件名右侧放语言切换；右侧为搜索、锁定、设置入口。

## 2. 条目字段

| 字段 | 录入方式 | 展示 | 复制 |
| --- | --- | --- | --- |
| 标题 title | 手输，必填 | 列表主标题 | — |
| 账号 username | 手输 + 账号预设下拉 | 显示明文（解锁态） | 每行复制按钮 |
| 密码 password | 手输 / 生成器填入 | 默认可明文显示，提供显示/隐藏切换 | 复制按钮 + 生成入口 |
| 邮箱 email | 手输 + 邮箱预设下拉 | 明文 | 复制按钮 |
| 手机号 phone | 手输 + 手机预设下拉 | 明文 | 复制按钮 |
| 网址 url | 手输 | 可点击打开 + 复制 | 复制按钮 |
| 备注 notes | Markdown 编辑器（弹窗） | 列表显示摘要/预览片段 | 打开编辑弹窗 |

### 2.1 预设值（R6）

- 在设置或条目表单中维护"我的预设"：按字段类型（账号/邮箱/手机号）分组，每条有显示名 + 值。
- 表单对应字段旁提供下拉，选择后填入值；预设值本身加密存储（见 `04` `presets` 表）。
- 预设值可新增/编辑/删除；不预设密码，密码一律由生成器或手动输入。

### 2.2 字段复制（R7）

- 每个可复制字段右侧独立复制按钮，点击后写入剪贴板并给出 Toast 反馈。
- 复制后按钮短暂变为"已复制"状态；后续版本加剪贴板超时自动清空（路线图）。
- 复制动作不触发联网，不写入历史剪贴板的特殊处理列入后续。

## 3. Markdown 备注（R4 / R5）

- **编辑**：条目通过"打开备注/编辑条目"进入独立弹窗（Dialog；后续可替换为独立 `WebviewWindow`）。备注区为 Markdown 编辑，带基础工具栏（标题、加粗、斜体、链接、列表、代码块、引用）。
- **预览**：弹窗内 Tabs 切换"编辑 / 预览"，预览用 markdown-it 渲染；安全处理（关闭原始 HTML / 过滤链接协议）在渲染层落实。
- **列表展示**：右侧条目卡片只显示备注纯文本摘要（去除 Markdown 标记，截断行数），完整内容在弹窗查看。
- 备注全文加密落库（`notes_enc`）。

## 4. 强密码生成器（R8）

- 入口：条目表单密码字段旁"生成"按钮，或独立生成器面板。
- 选项：
  - 长度滑块/输入（建议 12–64，默认 16）。
  - 复选：大写 `A-Z`、小写 `a-z`、数字 `0-9`、符号 `!@#$…`。
  - 开关：排除易混字符（`0 O l 1 I` 等）。
  - 至少保证选中字符集里出现各类字符（若勾选了多类，结果每类至少一个）。
- 行为：本地 CSPRNG 生成；提供"重新生成"；可"填入密码字段"；随条目一并保存（保存时走加密落库）。
- 生成器本身不持久化密码，除非用户保存为条目。

## 5. 新增 / 编辑 / 删除条目

- 新增：右侧"新增条目"按钮 → 弹窗表单 → 保存入当前分类（可在表单内改分类）。
- 编辑：卡片"更多 → 编辑"或点击卡片 → 弹窗回填 → 保存更新 `updated_at`。
- 删除：二次确认；MVP 物理删除（`deleted_at` 字段已预留回收站）。
- 所有写操作经 Rust 命令，事务内完成；失败回滚并 Toast 报错。

## 6. 解锁与主密码（衔接 R9）

- 首次启动：设置主密码（强度提示：长度/字符类），确认两次一致。
- 启动：未解锁只显示解锁页；校验通过进主界面。
- 顶部"锁定"：清空会话密钥回到解锁页；锁定后前端列表不再持有明文。
- 主密码修改、恢复码等列入后续路线，MVP 只做设置/解锁/锁定。

## 7. 验收要点（MVP 可演示闭环）

1. 能创建分类、在分类下新增条目，字段含账号/密码/邮箱/手机/网址/Markdown 备注。
2. 预设下拉可选已保存的账号/邮箱/手机号；每个字段可一键复制。
3. 生成器可调选项生成强密码，填入并保存到条目。
4. 备注可在弹窗编辑 Markdown、切换预览；列表显示摘要。
5. 关闭重开程序需主密码解锁；直接查数据库文件看不到账号/密码/邮箱/手机/备注明文。
6. 界面可在中/英文间切换，切换后顶部与主要文案跟随。
7. 可导出加密备份文件，并能从该文件恢复；数据库文件可手动拷贝迁移（见 `06`）。
