# 07 · 国际化（中英文切换）方案

## 1. 目标

- 界面支持简体中文（`zh-CN`）与英文（`en`），可在顶部标题栏右侧的语言图标按钮一键切换（弹出语言选择窗口）。
- 方案预留更多语言（后续可加 `ja-JP` 等），新增语言只补词条文件，不改组件。
- 语言偏好持久化到本地非敏感配置（`meta` 表 / 前端存储），下次启动跟随。

## 2. 技术选型

- 库：`vue-i18n`（Vue 3 官方生态）。
- 词条文件：`src/locales/<locale>.json`，按命名空间组织。
- 回退：缺词条时回退到 `zh-CN`（`src/i18n/index.ts` 的 `fallbackLocale`），并在开发态告警缺失 key。

## 3. 目录与词条结构

```
src/locales/
├── zh-CN.json
└── en.json
```

词条按模块分组：

```json
{
  "app": { "name": "Mend", "tagline": "修补你的记忆缺口" },
  "nav": { "all": "全部", "uncategorized": "未分类", "search": "搜索" },
  "entry": {
    "title": "标题", "username": "账号", "password": "密码",
    "email": "邮箱", "phone": "手机号", "url": "网址", "notes": "备注",
```

## 4. 切换入口与行为

- 位置：顶部标题栏右侧的语言图标按钮（`components/layout/TitleBar.vue`），点击弹出语言选择窗口（`components/language/LanguageDialog.vue`），在 `zh-CN` / `en` 间二选一（按钮 `aria-label` 走 `header.language` 词条，选项走 `header.langZh` / `header.langEn`）。
- 切换后：立即更新界面文案并关闭弹窗；写入偏好；不影响已解锁的会话状态。
- 首次启动：跟随系统语言（`navigator.language`，`zh` 前缀取 `zh-CN`，其余取 `en`）；已有存储偏好时优先跟随偏好。

## 5. 组件接入约定

- 模板内统一使用 `$t('entry.title')` 或 `t('entry.title')`；**禁止在组件/脚本里硬编码中或英文字面量**作为界面文案。
- 带插值的文案使用具名参数：`$t('common.deleteConfirm', { title: entry.title })`。
- 日期、数量、密码强度等使用 locale 感知的格式化工具，不拼接裸字符串。
- 错误提示契约：Rust 侧 `MendError` 序列化为结构化对象 `{ code, message }`，`code` 取值 `vault` / `db` / `crypto` / `not_found` / `locked`；前端 `src/lib/errorMessage.ts` 按 `code` 映射 `error.*` 词条展示，`code` 缺失或未知时用后端 `message` 兜底（旧格式的纯字符串错误走同一条兜底路径）。**禁止**在组件里直接展示后端原始英文/中文串或自行拼接错误文案。

## 6. 文案与新增流程

- 新增界面文案时：先在 `zh-CN.json` 与 `en.json` 同时加 key，再在组件引用。
- 词条 key 按 `模块.子项` 命名；通用词放 `common`，避免重复造同义词。
- 软件名 `Mend` 作为品牌名不翻译；标语可本地化。

## 7. 验收

- 切换中/英后，标题栏提示、侧栏、列表字段、弹窗、生成器、备份/设置弹窗文案全部跟随。
- 关闭重开后保持上次选择的语言。
- 临时新增第三种语言时，仅需新增 `locales/xx.json` 并在语言列表注册，组件无需改动。
