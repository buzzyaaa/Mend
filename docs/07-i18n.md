# 07 · 国际化（中英文切换）

> 0.4.0 起实现改为 **nsh/i18n + rust-i18n 词条格式**，不再使用 vue-i18n。旧内容保留在 Git 历史中。

## 1. 目标

- 支持简体中文（`zh-CN`）与英文（`en`），运行时可即时切换。
- 新增语言只补 `locales/<locale>.json`，不改组件。
- 语言偏好持久化在非敏感配置（nsh `Storage`），下次启动跟随；未选择时跟随系统。

## 2. 词条格式

```
locales/
├── en.json
└── zh-CN.json
```

- rust-i18n v1 格式：一个文件一种语言，文件名即 locale；嵌套对象，flatten 后为 `模块.子项`。
- 插值使用 `%{name}`，由 nsh `t("key", { name })` 填充。
- `nsh.json` 的 `"locales": ["en", "zh-CN"]` 决定随包发布的语言数据（数字/日期格式）。
- 两个词条的扁平 key 集合必须完全一致；`locales/` 下另有说明文件。

## 3. 使用

```tsx
import { t } from "nsh/i18n";

<Text>{t("entry.title")}</Text>
<Text>{t("settings.minutes", { n: 15 })}</Text>
```

- 在 JSX / computed 中读取 `t()` 会跟随 `setLocale` 响应式更新。
- 切换语言：`setLocale("zh-CN")` / `setLocale("en")`；`null` 表示跟随系统。
- 语言偏好由 `lib/preferences.ts` 写入 nsh `Storage`，解锁前也能生效。

## 4. 约定

- 组件中**不得硬编码**界面中/英文字符串；新增文案同时在两个 locale 添加。
- 错误：原生模块返回 `code|message`；`lib/errors.ts` 按 code 映射 `error.*` / `entry.*` 等词条，未知 code 才显示原始 message。
- 日期/数字使用 `Intl`（`lib/format.ts`），标题排序使用 `localeCompare`（带 fallback）。
- 分类图标名是数据库中的稳定字符串，显示时映射 emoji，不参与翻译；分类名是用户数据，不翻译。
