# 07 · 国际化（中英文切换）方案

## 1. 目标

- 界面支持简体中文（`zh-CN`）与英文（`en`），可在左上角软件名右侧一键切换。
- 方案预留更多语言（后续可加 `ja-JP` 等），新增语言只补词条文件，不改组件。
- 语言偏好持久化到本地非敏感配置（`meta` 表 / 前端存储），下次启动跟随。

## 2. 技术选型

- 库：`vue-i18n`（Vue 3 官方生态）。
- 词条文件：`src/locales/<locale>.json`，按命名空间组织。
- 回退：缺词条时回退到 `zh-CN`（或 `en`，实现时确定），并在开发态告警缺失 key。

## 3. 目录与词条结构

```
src/locales/
├── zh-CN.json
└── en.json
```

词条按模块分组：

```json
{
  "app": { "name": "Mend", "tagline": "修补你的记忆缺口" },
  "nav": { "all": "全部", "uncategorized": "未分类", "search": "搜索" },
  "entry": {
    "title": "标题", "username": "账号", "password": "密码",
    "email": "邮箱", "phone": "手机号", "url": "网址", "notes": "备注",
    "copy": "复制", "copied": "已复制", "edit": "编辑", "delete": "删除"
  },
  "generator": { "title": "密码生成器", "length": "长度", "uppercase": "大写", "lowercase": "小写", "digits": "数字", "symbols": "符号", "excludeAmbiguous": "排除易混字符", "regenerate": "重新生成", "fill": "填入" },
  "notes": { "edit": "编辑备注", "preview": "预览", "write": "编辑" },
  "backup": { "export": "导出备份", "import": "恢复备份" },
  "settings": { "language": "语言", "theme": "主题" },
  "common": { "save": "保存", "cancel": "取消", "confirm": "确认", "deleteConfirm": "确定删除该条目？" }
}
```

## 4. 切换入口与行为

- 位置：顶部栏左侧，Logo + `app.name` 右侧，放语言切换控件（下拉或中/英开关）。
- 切换后：立即更新界面文案；写入偏好；不影响已解锁的会话状态。
- 首次启动：跟随系统语言（`navigator.language`），匹配不到则默认 `zh-CN`。

## 5. 组件接入约定

- 模板内统一使用 `$t('entry.title')` 或 `t('entry.title')`；**禁止在组件/脚本里硬编码中或英文字面量**作为界面文案。
- 带插值的文案使用具名参数：`$t('common.deleteConfirm', { title: entry.title })`。
- 日期、数量、密码强度等使用 locale 感知的格式化工具，不拼接裸字符串。
- 错误提示：Rust 后端返回错误码，前端按错误码映射词条，不直接展示后端原始英文/中文串。

## 6. 文案与新增流程

- 新增界面文案时：先在 `zh-CN.json` 与 `en.json` 同时加 key，再在组件引用。
- 词条 key 按 `模块.子项` 命名；通用词放 `common`，避免重复造同义词。
- 软件名 `Mend` 作为品牌名不翻译；标语可本地化。

## 7. 验收

- 切换中/英后，顶部栏、侧栏、列表字段、弹窗、生成器、备份/设置入口文案全部跟随。
- 关闭重开后保持上次选择的语言。
- 临时新增第三种语言时，仅需新增 `locales/xx.json` 并在语言列表注册，组件无需改动。
