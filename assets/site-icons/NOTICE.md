# Website icon attribution

The SVGs in this directory are monochrome brand glyphs used to identify the
website stored in an entry. All of them are rewritten to `fill="currentColor"`
so the UI can tint them with the brand color at runtime.

## Simple Icons

Source: [Simple Icons](https://simpleicons.org/) v16, v14 and v12
(`simple-icons` npm package, [CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/)).

v14/v12 assets are used only for brands that later versions removed
(Microsoft, Outlook, OneDrive, Teams, LinkedIn, Amazon, AWS, OpenAI, Heroku,
Adobe, Magento, Slack, Twilio, Canva, SendGrid).

## Material Design Icons

The Bing glyph comes from [Material Design Icons](https://pictogrammers.com/library/mdi/)
(`mdi:microsoft-bing`, [Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0)).
Simple Icons no longer distributes a Bing icon.

No network requests are made at runtime: every glyph is bundled with the app.
